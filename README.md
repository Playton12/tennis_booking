## 📋 О проекте

**БроньКорт** — одностраничное веб-приложение (SPA) для поиска и бронирования теннисных кортов. Пользователь может просмотреть доступные корты, выбрать покрытие, дату и время, добавить бронь в корзину и оформить заказ. Проект поддерживает тёмную и светлую тему, геолокацию для расчёта расстояний, а также полностью адаптивен для мобильных устройств.

## ✨ Возможности

- **🏠 Главная страница** — герой-секция с поиском, популярные корты, статистика сервиса
- **🔍 Поиск и фильтрация** — поиск по городу/адресу, фильтрация по типу покрытия (грунт, хард, трава, крытые/открытые)
- **📍 Геолокация** — определение ближайших кортов на основе GPS пользователя (с кэшированием сессии)
- **📅 Бронирование** — выбор корта → выбор даты (календарь) → выбор времени → длительность (1 / 1.5 / 2 часа)
- **🛒 Корзина** — добавление, удаление бронирований, подтверждение заказа
- **👤 Профиль** — история бронирований, статистика, платёжные данные, настройки
- **🌙 Тёмная тема** — автоматическое определение системной темы + ручной переключатель
- **📱 Адаптивный дизайн** — корректное отображение на десктопе, планшете и телефоне
- **♿ Доступность** — skip-link, ARIA-атрибуты, семантическая вёрстка, keyboard navigation
- **💾 Персистентность** — сохранение темы, экрана, корзины и геопозиции в localStorage / sessionStorage

## 🛠 Технологии

| Технология | Описание |
|------------|----------|
| **HTML5** | Семантическая структура, ARIA-атрибуты |
| **CSS3** | CSS-переменные (OKLCH), `clamp()`, Grid, Flexbox, анимации, media queries |

## 📁 Структура проекта

```
tennis_booking/
├── des.html          # Единственная страница приложения (SPA)
└── README.md         # Документация
```

Приложение реализовано как single-page application в одном HTML-файле — навигация между экранами (Главная / Бронирование / Профиль) происходит через JavaScript без перезагрузки страницы.

## 🚀 Запуск

1. Откройте файл `des.html` в любом современном браузере:
   ```
   Откройте des.html двойным кликом или перетащите в браузер
   ```
2. Готово! Приложение полностью работает на клиенте без серверной части.

### Локальная разработка

```bash
# Через Python (если установлен)
python -m http.server 8000

# Или через Node.js
npx http-server .
```

Затем откройте `http://localhost:8000/des.html`.

## 🎨 Дизайн

- **Шрифты**: Inter (тело) + JetBrains Mono (заголовки/UI)
- **Цветовая схема**: OKLCH с поддержкой light/dark mode
- **Композиция**: CSS Grid для сеток, Flexbox для компонентов
- **Анимации**: CSS transitions для интерактивности, keyframe для появления экранов
- **Адаптивность**: 3 брейкпоинта — десктоп, планшет (768px), телефон (480px)

## 📐 Экраны приложения

| Экран | Описание |
|-------|----------|
| **Главная** | Герой-секция, поиск, фильтры, популярные корты, CTA-блок |
| **Бронирование** | Каталог кортов с фильтрами → форма выбора даты/времени/длительности → корзина |
| **Профиль** | Данные пользователя, история бронирований, статистика, настройки |

## 📊 Данные

Приложение использует моковые данные, хранящиеся в JavaScript-объекте `courts`:

- 4 корта с разными покрытиями (грунт, хард, трава)
- Адреса, цены за час, координаты для расчёта расстояний
- Теги удобств (освещение, раздевалка, VIP-зона и т.д.)

## 🔒 Приватность

- Геолокация используется **только в рамках сессии** и не сохраняется постоянно
- Данные корзины и темы хранятся в `localStorage` устройства пользователя
- Данные не отправляются на какие-либо серверы
